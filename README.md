# Qiansai — 基于多模态感知的智能汽车无感交互与安防系统

嵌入式竞赛作品工程源代码。系统以 **树莓派5** 为中枢、多块 **ESP32** 为感知节点，融合 **UWB、毫米波雷达、NFC、IMU** 等多模态传感器，实现智能汽车的无感交互与安防。

## 主要功能

1. 车主无感交互开关车门（靠近车身约 1m 开门，远离约 2m 关门）
2. 陌生人越过电子围栏警戒线，自动开启摄像头录音录像并保存
3. 人脸识别车主开门
4. NFC 卡 / 车钥匙按键开关车门
5. 车辆受到擦碰通过云平台（ThingsCloud MQTT）微信预警
6. 车载 Qt UI 实时显示车门状态、附近行人坐标、摄像头状态与录像回放

## 系统架构

```
毫米波雷达(BLE1/2/3 级联) ──BLE──▶ anchor(主控ESP32) ──UART──▶ 树莓派 Qt 界面
UWB 标签(车主随身/tag)   ──UWB测距──▶ anchor                       │
                                                          文件通信 ▼
                                              camera(Python 人脸识别/录像) ──▶ 开门/录像
```

## 目录结构

| 目录 | 说明 |
|---|---|
| `qt/` | 树莓派车载 UI（Qt/C++）。串口解析行人坐标、四页面显示、分区摄像头控制、人脸开门。 |
| `camera/` | 树莓派人脸识别与录像（Python + face_recognition）。`control_file.py` 调度 4 路 `videoX.py`；通过文件与 Qt 通信。 |
| `环境监测节点代码/anchor/` | 车端主控 ESP32：BLE 汇聚雷达数据 + UWB 测距 + MPU6050 擦碰检测 + WS2812 灯 + UART 上传。 |
| `环境监测节点代码/tag/` | 车主随身 UWB 标签：按键开关门 + UWB 应答。 |
| `环境监测节点代码/BLE1~BLE3/` | 毫米波雷达采集节点（HiLink 2450），BLE 级联上报；BLE2 含 PN532 NFC 开门。 |
| `环境监测节点代码/thingscloud/` | 擦碰事件上云（ThingsCloud MQTT）触发微信预警。 |

## 硬件 / 平台

- 主控：树莓派5、ESP32（esp32dev，Arduino 框架，PlatformIO 构建）
- 传感器：DW3000 UWB、HiLink LD2450 毫米波雷达、PN532 NFC、MPU6050 IMU
- 执行：WS2812B 灯带、继电器门锁、摄像头

- `环境监测节点代码/*/src/` 下的 `dw3000_*`、`MPU6050*`、`I2Cdev*` 为第三方芯片驱动库，自写代码主要在各 `start.cpp` / `main.cpp` / `uwb.cpp`。
