# 物理接线图解（杜邦线怎么接）

> 本文只讲**实际动手接线**：哪根线从哪接到哪。引脚号均从工程源代码核实。
> 配套阅读：[硬件架构与接线说明](硬件架构与接线说明.md)（含框架、数据流、搭建步骤）。

## 有线 vs 无线

- **无线，不用接线**：anchor↔tag 的 UWB 测距；BLE1→BLE2→BLE3→anchor 的 BLE 级联；thingscloud↔路由器的 WiFi。
- **要用杜邦线接的**：每块 ESP32 到它自己挂的传感器/模块，外加两根**跨板信号线**。

## 通用前提（重要）

- 所有模块**必须共 GND**（地线连通），否则串口/信号线通信会乱。
- DW3000 / LD2450 / PN532 / MPU6050 均为 **3.3V 逻辑**，注意供电与电平匹配，别接反。

---

## ① anchor（车端主控 ESP32）— 5 组接线

### a. DW3000 UWB（SPI，6 线）
| DW3000 | ESP32 GPIO |
|---|---|
| SCK | 18 |
| MISO | 19 |
| MOSI | 23 |
| CS/SS | 5 |
| RST | 27 |
| IRQ | 34 |
| VCC / GND | 3.3V / GND |

### b. MPU6050 IMU（I2C，2 线）
| MPU6050 | ESP32 |
|---|---|
| SDA | 21 |
| SCL | 22 |
| VCC / GND | 3.3V / GND |

### c. WS2812B 灯带（1 线）
DIN → GPIO **25**；VCC/GND → 5V/GND。

### d. 跨板线①：接树莓派（串口，3 线，**交叉接**）
| anchor | 树莓派 |
|---|---|
| GPIO17 (TX) | → Pi RX |
| GPIO16 (RX) | ← Pi TX |
| GND | ↔ Pi GND |

> ⚠️ TX 接对方 RX、RX 接对方 TX（交叉），不要 TX-TX 直连。树莓派侧为 `/dev/ttyAMA0`，115200。

### e. 跨板线②：擦碰信号 → thingscloud（1 信号线 + 共地）
- anchor **GPIO4** → thingscloud **GPIO4**
- 两板 **GND 相连**
- 含义：anchor 检测到擦碰把该线拉高，thingscloud 读到高电平即联网报警。

---

## ② tag（车主标签 ESP32）— 2 组接线

### a. DW3000 UWB
接法与 anchor 完全相同：18/19/23/5/27/34 + 3.3V/GND。

### b. 两个按键（各 1 线到 GPIO，另一端到 GND）
| 按键 | ESP32 | 另一端 |
|---|---|---|
| 开门键 | GPIO 4 | GND |
| 关门键 | GPIO 25 | GND |

> 使用内部上拉（INPUT_PULLUP），按键**无需外接电阻**，直接短到 GND。
> tag 与 anchor 之间靠 UWB **无线**测距，两板之间**不接任何导线**。

---

## ③ BLE1 / BLE2 / BLE3（3 个雷达节点）

### 共同：每块各接 1 个 LD2450 毫米波雷达（串口，交叉，2 信号线 + 供电）
| LD2450 | ESP32 |
|---|---|
| 雷达 TX | → ESP32 GPIO16 (RX) |
| 雷达 RX | ← ESP32 GPIO17 (TX) |
| VCC / GND | 5V / GND |

> 波特率 **256000**（LD2450 默认），勿与调试串口 115200 混淆。

### BLE2 额外：PN532 NFC（I2C + 2 控制脚）
| PN532 | ESP32 |
|---|---|
| SDA | 21 |
| SCL | 22 |
| IRQ | 4 |
| RSTPDN | 5 |
| VCC / GND | 3.3V / GND |

> PN532 模块背面拨码需拨到 **I2C 模式**。

### BLE2 额外：继电器（门锁，1 信号线）
- 继电器 IN → GPIO **23**；继电器 VCC/GND 供电。
- 继电器输出（COM/NO）串入门锁供电回路，NFC 验证通过时通电解锁 5 秒。

> BLE1/2/3 之间及到 anchor 全靠 **BLE 无线**级联，板间不接导线；换板后需把各自 MAC 填入下游节点代码的 `slaveMacs[]`。

---

## ④ thingscloud（擦碰上云 ESP32）— 1 组接线

- **GPIO4** ← 来自 anchor GPIO4 的信号线
- **GND** ↔ anchor GND
- 仅此一根信号线 + 共地，其余靠 WiFi。

---

## ⑤ 树莓派 5

- **UART**：TX/RX/GND ↔ anchor（见 ①-d），设备 `/dev/ttyAMA0`。
- **USB ×4**：4 个 USB 摄像头（识别为 video0 / video2 / video4 / video6）。

---

## 物理连线总览（只画有导线的部分）

```
[LD2450]─串口─[BLE1]                    ┈BLE┈(无线)
[LD2450]─串口─[BLE2]─I2C─[PN532]        ┈BLE┈
                    └─GPIO23─[继电器]─[门锁]
[LD2450]─串口─[BLE3]                    ┈BLE┈
                                          ↓(无线汇聚)
[DW3000]─SPI─┐                        ┌─[anchor]
[MPU6050]─I2C┼──────[anchor]──────────┤ GPIO16/17 ─串口(3线)─ [树莓派] ─USB─ [4×摄像头]
[WS2812]─────┘                        │ GPIO4 ─信号线(2线)─ [thingscloud] ┈WiFi┈ 云
                                       
[DW3000]─SPI─[tag]─按键×2      tag 与 anchor: ┈UWB┈(无线, 无导线)
```

## 接线自检清单

- [ ] 所有模块 GND 是否连成一片（含跨板的 anchor↔Pi、anchor↔thingscloud）？
- [ ] anchor↔树莓派串口是否 TX-RX **交叉**？
- [ ] 各 LD2450 与 ESP32 串口是否 TX-RX **交叉**、波特率 256000？
- [ ] DW3000/MPU6050/PN532 供电是否 3.3V、未接成 5V？
- [ ] PN532 拨码是否在 I2C 模式？
- [ ] 换过板子后，下游节点 `slaveMacs[]` 的 MAC 是否已更新？
