1.  BLE实现了雷达1--雷达2--雷达3--tag，360°范围可以实现自动开关门（除雷达检测盲区）
2.  雷达获取位置数据进行坐标转换，以车体正中心为坐标原点，将数据通过串口传输给树莓派QT显示
3.  车主（携带钥匙者），距离车身周围1m开门，2m关门
4.  车钥匙与车身锚点基于uwb技术无线通信，可实现测距（精度10cm），以及按键远程操作开关门
5.  NFC检测，将数据通过BLE传输至车身锚点，实现绿灯开门
6.  人脸识别开门，可通过串口接收来自树莓派人脸识别到车主的信号，进行开门
7.  擦碰检测，通过MPU6050检测车身震动信息，若受到擦碰，可使用WiFi模块连接thingscloud云平台进行报警传输，进而发至微信公众号预警信息，可在微信关闭预警
